# Roadmap do FluxoCRM

## Fase 0 - Planejamento inicial
Objetivo: consolidar a visão do produto, público-alvo, escopo e regras básicas.

Entregas previstas:
- documento mestre do projeto;
- definição do MVP;
- regras de negócio iniciais;
- priorização de funcionalidades.

## Fase 1 - Definição do MVP
Objetivo: transformar o conceito em uma especificação objetiva.

Entregas previstas:
- fluxos de cadastro de clientes;
- fluxos de atendimento;
- fluxos de agendamento;
- estrutura de mensagens prontas.

## Fase 2 - Validação conceitual
Objetivo: validar se o modelo atende às necessidades de pequenos negócios.

Entregas previstas:
- revisão do fluxo com usuários reais;
- ajustes de usabilidade e regras;
- priorização final das funcionalidades do MVP.

## Fase 3 - Preparação para desenvolvimento
Objetivo: deixar o projeto pronto para implementação técnica.

Entregas previstas:
- definição da arquitetura de alto nível;
- escolha das tecnologias;
- definição de critérios de aceitação;
- organização inicial do backlog.

## Fase 4 - Implementação do MVP
Objetivo: construir a versão inicial do sistema.

Entregas previstas:
- dashboard;
- cadastro de clientes;
- gestão de atendimentos;
- agendamentos;
- mensagens prontas.

## Decisões de escopo ao longo do roadmap
- evitar expansão do escopo antes da validação do MVP;
- priorizar entregas simples e testáveis;
- adiar integrações e recursos avançados para fases futuras.

## Próximo passo recomendado
Concluir a especificação do MVP e preparar uma lista inicial de histórias de usuário para dar início ao processo de desenvolvimento.
