# FluxoCRM

## O que é o projeto
FluxoCRM é um projeto de planejamento para um sistema de automação de atendimento e fluxo de clientes voltado para pequenos negócios.

## Status atual
O projeto encontra-se em fase inicial de documentação e organização de ideias, sem desenvolvimento de aplicação ainda.

## Tecnologias
As tecnologias ainda estão indefinidas, pois o objetivo atual é definir escopo, MVP, regras de negócio e roadmap.
